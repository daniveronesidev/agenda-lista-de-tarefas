🚀 Como Executar
1️⃣ Clone o repositório
git clone https://github.com/daniveronesi/agenda-lista-de-tarefas.git
2️⃣ Acesse a pasta do projeto
cd agenda-lista-de-tarefas
3️⃣ Compile o projeto
kotlinc agenda.kt -include-runtime -d agenda.jar
4️⃣ Execute o sistema
java -jar agenda.jar
